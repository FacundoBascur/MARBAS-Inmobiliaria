⚠️  PUNTOS CRÍTICOS DE CONFIGURACIÓN:
════════════════════════════════════════════════════════════════════════════════

🔑 JWT_SECRET
   • Debe ser único y fuerte (32+ caracteres)
   • Cambiar del valor default "MarbasSecreto2026"
   • Nunca hardcodear, usar variables de entorno

📧 EMAIL_PASSWORD
   • Para Gmail: usar "Contraseña de Aplicación"
   • Generar en: https://myaccount.google.com/apppasswords
   • NO usar la contraseña de la cuenta

🌐 ALLOWED_ORIGINS
   • Agregar dominio de tu frontend
   • Separar múltiples dominios con comas
   • En desarrollo: http://localhost:3000,http://localhost:5173

🔒 .env
   • NUNCA commitar a git
   • Ya está en .gitignore ✅
   • Usar .env.example como template


🧪 COMANDOS DE PRUEBA:
════════════════════════════════════════════════════════════════════════════════

# Obtener propiedades (GET - público)
curl http://localhost:3000/api/propiedades

# Login
curl -X POST http://localhost:3000/api/login \
  -H "Content-Type: application/json" \
  -d "{\"usuario\":\"admin\",\"password\":\"pass\"}"

# Crear propiedad (POST - requiere token)
curl -X POST http://localhost:3000/api/propiedades \
  -H "Authorization: Bearer TOKEN_AQUI" \
  -F "title=Casa" -F "price=100000" -F "location=Centro"

# Enviar contacto
curl -X POST http://localhost:3000/api/contacto \
  -H "Content-Type: application/json" \
  -d "{\"nombre\":\"Juan\",\"email\":\"juan@email.com\",\"mensaje\":\"Hola\"}"
